# Getting help

- **Questions and how-tos:** read the [README](README.md) first; it documents the shader language,
  the API and the known [limitations](README.md#limitations). If it doesn't answer your question,
  [open an issue](https://github.com/shanto462/SharpCompute/issues/new/choose) and describe what you
  are trying to do.
- **Bugs:** open a [bug report](https://github.com/shanto462/SharpCompute/issues/new?template=bug_report.yml)
  with a small shader that shows the problem, and whether it also happens with `ForCpu`.
- **Feature ideas:** open a
  [feature request](https://github.com/shanto462/SharpCompute/issues/new?template=feature_request.yml).
- **Security problems:** report them privately, as the [security policy](SECURITY.md) describes,
  never in a public issue.

SharpCompute has one maintainer, so answers are best effort. Only macOS 15+ on Apple Silicon is
supported today; Vulkan and OpenGL are on the [roadmap](README.md#roadmap), not yet available.
